# SYNTHETIC test data: not real observations

Every file here is generated by `tests/make_sample_data.py` for the test suite only.
It is never read by the web app and must never be shown as real fire data.

The ground truth is built in: MODIS→SNPP factor = 4.0, SNPP→NOAA-20 factor = 0.9,
and the harmonized count is `18 × k(year, month)` (see the generator's docstring).
